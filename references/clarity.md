# 写实类表情糊了怎么处理

适用场景：写实人物、照片宠物、细节繁密的插画，或用户直接反馈"脸糊了"。

如果用户要的就是像素画外观，那就走像素风，别给每一套都套写实处理。

## 先诊断，再重生成

把原始透明精灵裁切，和从导出 GIF 里解码出来的一帧，**放到同一显示尺寸下并排看**，顺便也看一下解码后的 MP4。这样才能分清问题出在：源素材本身软、合成器像素化、还是播放时被缩放。

`--render-style pixel` 模式下的行为是刻意设计的：`export_pack.py` 会把精灵缩到约 106 像素高，放到 160 × 160 画布上，再用最近邻放大到 320 × 320。这能做出像素味，但照片来源的面部细节在这一步就被丢弃了。**把这个结果再放大、或只改最终输出尺寸，都补不回来。**

如果原始裁切本身就软，或脸只占了很少的源像素，那就去要一张更清晰的参考图，或重新生成一张脸更大的姿势。**不要承诺缩放能恢复丢失的细节或身份特征。**

## 内置高清导出（默认）

直接跑普通导出命令，不需要额外参数，也不需要改合成脚本：

```sh
python3 scripts/export_pack.py manifest.json build --font /path/to/font.ttf --preview
```

默认就是 `hd` + 512 × 512，老清单里没有渲染字段时也一样。清单里可以显式写 `"render_style": "hd"` 或 `"render_style": "pixel"`；`--render-style hd` / `--render-style pixel` 会覆盖清单里的设置。

**只有确定要像素外观时才选 pixel。不要根据图像内容自动猜，然后把一张人脸静默切到像素模式。**

HD 预览是原尺寸的干净网格，默认不叠标题。想要分类标题就加 `--preview-layout chapters`；`--preview-layout clean` 在像素导出下也能用。离线画廊对 HD 用常规采样，对像素画用最近邻采样。

## 高清路径是怎么保住细节的

内置实现按下面这套已验证的做法走：

1. **每一帧都从原始高分辨率图集裁切开始**。遵守已验收的格子边界与裁切范围。按有意义的 alpha 边界裁，先丢掉低 alpha 的生成噪点，再适配精灵。
2. **直接在最终 GIF 分辨率上合成**。HD 输出是 **512 × 512**，不是 160 像素的中间画布。精灵控制在**约 400 像素宽、330 像素高**，落底大约在 **y=390**，给台词和动效留空间。这些是起点值，不是每个姿势都必须照抄的硬指标。
3. **缩放用 LANCZOS**，逐帧做。连续仿射/错切形变**用 BICUBIC 采样**。人脸不要用最近邻，也不要用粗糙的横向条带形变。只有装饰性像素图标、且确实要那个味道时，才保留最近邻。
4. **把动效偏移从 160 单位设计空间换算到最终画布**（`final_size / 160`）。安全边距计算要把完整的跳跃、挤压、错切都算进去。形变后的精灵外围补透明留白，避免被裁。如果某个动效顶到边缘，降低精灵占比或动效幅度，重新导出。
5. **台词和描边在最终尺寸上渲染**。已确认的文字和表情不要改。在验证过的 512 构图里，台词居中在 y≈450 附近，字号约 56–62 像素。长台词按可用宽度压缩适配。
6. **成帧后量化到同一套 GIF 调色板**，预留一个透明索引，使用 disposal mode 2。平滑边缘在最终分辨率上一次性栅格化即可，别反复做 alpha 阈值化和放大。GIF 调色板有限、透明只有二值，所以皮肤渐变和边缘要在对比底色上看一遍。
7. **保留原本的时长设计**。现有套包是 24 帧 × 80 ms = **1.92 秒**，无限循环。编码器可能把相邻的相同帧合并，总时长不变。

## 交付前的验证

- 逐张解码最终 GIF，核对实际尺寸、循环标记、总时长、透明度、可见帧差异，以及整轮循环里的安全边距。
- MP4 预览用解码后的最终 GIF 帧来拼。需要时做平滑缩放，**但不要拿放大后的低分辨率预览当质量依据**。标题与标签按用户的选择来。
- 旧 GIF 和新 GIF 要**在同一显示尺寸**、可比的动画相位下对比。看眼睛、眼镜、头发、皮肤、衣物纹理。如果对比图是静帧，要说明清楚。
- 核对 ZIP 内容和 MP4 解码。写实类高分辨率 GIF 体积会更大；当体积或平台限制影响实际用途时，如实说明。**本地能播放，不能作为"兼容某个聊天平台"的证据。**

这套修正曾在 512 × 512 下、用同一份源素材重做过四张写实人物表情，去掉像素中间层后脸和衣物细节都有明显改善。这只能证明"这个渲染缺陷可以这样修"，不能保证任何源图都能被做清晰。
